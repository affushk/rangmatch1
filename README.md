# RangMatch Pro — Digital Textile Colour Matching Studio

Fabric-aware colour matching website + Android app for digital textile designers.

## Main features
- Upload JPG/PNG textile design and pick colours directly from the image.
- Automatic dominant palette extraction.
- Fabric selector: Cotton, Muslin, Rayon/Viscose, Georgette, Chiffon, Satin/Silk Look, Lawn/Cambric, Linen Look and Mixed/Not Sure.
- Master-demand modes: Light Pastel, Dusty, Bright Light, Contrast, Soft, Dark Rich, Premium Boutique and Commercial Mix.
- Generates 8 matching colourways with HEX/RGB, textile-friendly names and motif accent colours.
- Light/Dark, Soft/Bright, Dusty/Clean, Contrast and Warm/Cool controls.
- Lock approved matching cards and regenerate only unlocked options.
- Fabric Advisor suitability score and motif-family recommendations.
- Save sets in My Colour Book using local device storage.
- Export a high-resolution 2400 px PNG matching board.
- PWA install support; no paid API required.
- Android WebView app uses the same offline/local matching engine.

## Website
GitHub Pages workflow publishes the root static site automatically.

## Android APK
GitHub Actions builds `RangMatch-Pro.apk` and publishes a rolling `latest-build` release.

> Fabric advice and screen previews are design guidance, not scientific colour/lab prediction. Always approve a physical strike-off/sample before bulk production.
